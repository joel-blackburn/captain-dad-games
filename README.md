# Captain Dad Games

The home of Captain Dad's games: https://captaindad.games

A plain static site (no build step), deployed on Vercel from `main`.

- `index.html` – home: live low-poly 3D game shelf (`assets/js/island.js`, Three.js r128 from cdnjs), the Game Shelf, star hunt
- `sum-shredders/` – Sum Shredders game page (Play links go to https://www.sumshredders.com/)
- `captain-dad/` – Meet Captain Dad
- `grown-ups/` – parents and teachers
- `secrets/` – the Secret Room: badges and the secret code
- `assets/js/site.js` – menu, star hunt, badges, secret code, contact button
- `assets/css/site.css` – shared styles (Captain Dad palette, Baloo 2 + Nunito)
